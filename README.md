# co-wallet

Самохостируемое веб-приложение для учёта личных и семейных финансов с поддержкой совместных счетов и гибким распределением расходов между участниками.

## Возможности

- **Личные и совместные счета** — ведите финансы отдельно или вместе с семьёй
- **Распределение расходов** — настройте доли для каждого участника (50/50, 70/30 и любые другие), меняйте распределение по отдельной транзакции вручную
- **Категории и теги** — категории расходов/доходов; произвольные теги для гибкой фильтрации
- **Аналитика** — круговая диаграмма расходов по категориям, сводка баланса/доходов/расходов за выбранный период
- **Мультивалютность** — несколько валют с автоматическим обновлением курсов; переключение валюты отображения на дашборде
- **Мобильный интерфейс** — оптимизирован для смартфона, работает в браузере
- **Инвайт-регистрация** — пользователи добавляются только по приглашению администратора

## Стек

| Компонент | Технология |
|---|---|
| Backend | Go 1.25, chi, pgx/v5, goose, golang-jwt |
