# Руководство администратора

## Требования

- Docker и Docker Compose (версия с командой `docker compose`, не `docker-compose`)
- Открытый порт на сервере (по умолчанию 3000)

## Установка

### 1. Получить файлы

```bash
git clone https://github.com/co-wallet/docker.git
cd docker
```

### 2. Настроить переменные окружения

```bash
cp .env.example .env
```

Отредактируйте `.env`:

```env
# Обязательные
POSTGRES_PASSWORD=смените-на-надёжный-пароль
JWT_SECRET=длинная-случайная-строка-минимум-32-символа

# Публичный адрес приложения (используется в ссылках приглашений)
APP_URL=https://ваш-домен.ru

# Порт на хосте
APP_PORT=3000

# Аккаунт администратора (создаётся при первом запуске)
ADMIN_USERNAME=admin
ADMIN_EMAIL=admin@example.com
ADMIN_PASSWORD=НадёжныйПароль1!
# Если ADMIN_PASSWORD оставить пустым — пароль сгенерируется автоматически
# и будет напечатан в логах один раз при первом запуске

# SMTP для отправки приглашений (необязательно)
# Если не заданы — ссылки приглашений отображаются прямо в интерфейсе
SMTP_HOST=smtp.example.com
SMTP_PORT=587
SMTP_USER=no-reply@example.com
SMTP_PASS=пароль-smtp
SMTP_FROM=no-reply@example.com
```

### 3. Запустить

```bash
docker compose up -d
```

Приложение будет доступно по адресу `http://localhost:3000` (или по вашему домену).

### 4. Первый вход

При первом запуске автоматически создаётся аккаунт администратора с учётными данными из `.env`. Если `ADMIN_PASSWORD` не был задан, найдите сгенерированный пароль в логах:

```bash
docker compose logs backend | grep "Admin"
```

## Обновление

```bash
docker compose pull       # обновить образы (если используются готовые)
docker compose build      # пересобрать из исходников
docker compose up -d      # перезапустить
```

Миграции базы данных применяются автоматически при каждом запуске бэкенда.

---

## Резервная копия базы данных

**Создать бэкап:**
```bash
docker run --rm --network host postgres:16-alpine \
  pg_dump -U postgres -h localhost cowallet > cowallet_backup.sql
```

**Восстановить из бэкапа** (данные будут полностью заменены):
```bash
docker exec -i docker-db-1 psql -U postgres cowallet \
  -c "DROP SCHEMA public CASCADE; CREATE SCHEMA public; GRANT ALL ON SCHEMA public TO postgres;"
docker exec -i docker-db-1 psql -U postgres cowallet < cowallet_backup.sql
docker compose restart backend
```

## Управление пользователями

Откройте `/admin` в приложении (доступно только администраторам).

### Приглашение нового пользователя

1. Перейдите в **Администрирование → Приглашения**
2. Введите email нового пользователя и нажмите **Создать приглашение**
3. Скопируйте ссылку и отправьте пользователю вручную **или** настройте SMTP — тогда письмо отправится автоматически
4. Ссылка действительна **72 часа**

Пользователь перейдёт по ссылке, выберет имя, пароль и валюту по умолчанию.

### Блокировка пользователя

В разделе **Администрирование → Пользователи** можно деактивировать аккаунт. Заблокированный пользователь не сможет войти в систему.

## Управление валютами

Раздел **Администрирование → Валюты**.

- Курсы валют обновляются автоматически каждые 2 часа с открытого источника (open.er-api.com)
- Добавить новую валюту можно только если её код есть в таблице курсов (ISO 4217). Например: `USD`, `EUR`, `RUB`, `BYN`, `TRY`, `ILS`
- Валюту можно **отключить** — она исчезнет из списка при создании счетов и транзакций, но данные сохранятся
- Кнопка **Обновить курсы** запускает немедленное обновление вне расписания

## Переменные окружения — справочник

| Переменная | Обязательна | По умолчанию | Описание |
|---|---|---|---|
| `POSTGRES_PASSWORD` | да | — | Пароль PostgreSQL |
| `JWT_SECRET` | да | — | Секрет для подписи JWT-токенов |
| `APP_URL` | нет | `http://localhost:3000` | Публичный URL для ссылок приглашений |
| `APP_PORT` | нет | `3000` | Порт на хосте |
| `ADMIN_USERNAME` | нет | `admin` | Имя пользователя администратора |
| `ADMIN_EMAIL` | нет | `admin@co-wallet.local` | Email администратора |
| `ADMIN_PASSWORD` | нет | _(авто)_ | Пароль администратора; если пусто — генерируется и логируется |
| `SMTP_HOST` | нет | — | SMTP-сервер; если пусто — приглашения не рассылаются по email |
| `SMTP_PORT` | нет | `587` | SMTP-порт |
| `SMTP_USER` | нет | — | Логин SMTP |
| `SMTP_PASS` | нет | — | Пароль SMTP |
| `SMTP_FROM` | нет | `no-reply@co-wallet.local` | Адрес отправителя |

## Разработка

Для запуска с горячей перезагрузкой кода:

```bash
docker compose -f docker-compose.yml -f docker-compose.dev.yml up
```

В режиме разработки:
- бэкенд доступен напрямую на `http://localhost:8080`
- фронтенд — на `http://localhost:3000` (Vite dev server с HMR)
- база данных — на `localhost:5432`
